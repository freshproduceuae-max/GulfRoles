# 08 Maintenance and Handoff

Goal: leave the owner able to keep the site current, and record how changes are made.

Files:

- `handoff-prompt.md`
- `maintenance-guide-template.md`

## Dependencies

- `docs/operations/launch-checklist.md`

## Required Output

- `docs/operations/maintenance-guide.md`

## Success Criteria

- the owner has a plain-language guide to update text, swap photos, and add items
- how to request changes is explained
- a simple change log / version history is started
- backup and revert basics are explained

## Exit Criteria

- `docs/operations/maintenance-guide.md` exists and is written for a non-developer
- version history reflects the launch
- progress tracker marks the project live

## Handoff

- project is live and owned; future changes re-enter at the relevant phase and mark upstream artifacts stale when scope changes
