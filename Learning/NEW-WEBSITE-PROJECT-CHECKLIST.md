# New Website Project Checklist

Use this when starting a website project with the `Small Business Websites` folder.

## Start Step

- Copy the full `Small Business Websites/` folder into the new project root
- Confirm `Small Business Websites/START-HERE.md` exists
- Add the owner's photos, logo, and any copy into the reference folders
- Open the AI in the new project folder
- Tell the AI clearly to use the Small Business Websites folder as the project skeleton

## Phase Checklist

### 00 Operating Model
- Execution preferences captured (approvals, how much to ask, deploy target)
- Progress tracker initialized
- Decision log created

### 01 Business Discovery
- What the business does and who it serves captured
- Primary goal captured (calls, WhatsApp messages, quote/booking requests)
- Service area and hours captured
- Contact channels captured (phone, WhatsApp, social)
- Competitors/inspiration noted

### 02 Brand and Content
- Business name, tagline, and story captured
- Voice/tone agreed
- Full list of services/products/menu items confirmed (nothing dropped)
- Offers, testimonials, and FAQs captured if available
- CTA wording drafted

### 03 Assets and Media
- Every photo inventoried and named
- Logo captured
- Each site image slot mapped to a real file
- Rights/permission to use photos confirmed
- Large images flagged for optimization

### 04 Site Architecture
- Single-page vs multi-page decided
- Section list and order agreed
- Navigation and any dialogs/modals defined
- Mobile-first responsive behavior defined
- Accessibility basics noted

### 05 Build and Implementation
- Stack decided (static-first unless a need is proven)
- Design implemented as-is if one was provided
- Every referenced asset is a committed file
- Loading/success/error states handled
- Tested locally

### 06 Conversion and Integrations
- WhatsApp / call / quote paths wired
- Forms open pre-filled messages or a working handler
- Basic SEO meta and titles set
- Analytics added if requested

### 07 Deployment and Launch
- Repo created; node_modules and large files git-ignored
- Deployed to host (e.g. Vercel)
- Live URL verified: images load, links work, CTAs fire
- Domain connected if the owner has one

### 08 Maintenance and Handoff
- Plain-language guide for editing content and swapping images written
- How to request changes explained
- Version history and change log started

## Done Means

- the site reflects the real business, with all its services
- every image and the logo load on the live URL
- the owner has clear conversion paths
- the repo is clean and safe to redeploy
- the owner knows how to keep it updated
