# 04 Site Architecture

Goal: decide the site's shape — pages/sections, order, navigation, dialogs, and mobile behavior — before writing the build.

Files:

- `site-architecture-prompt.md`
- `site-architecture-template.md`

## Dependencies

- `docs/business/business-profile.md`
- `docs/brand/content-inventory.md`
- `docs/assets/asset-inventory.md`

## Required Output

- `docs/architecture/site-architecture.md`

## Success Criteria

- single-page vs multi-page decided with a reason
- section list and order agreed and mapped to content + image slots
- navigation defined
- any dialogs/modals/accordions defined (e.g. for long service lists)
- mobile-first behavior defined (what stacks, what becomes a sheet)
- accessibility basics noted (headings, alt text, focus, contrast, tap targets)

## Exit Criteria

- `docs/architecture/site-architecture.md` exists and is populated
- every section maps to real content and real image slots
- progress tracker updated

## Handoff

- next phase is `05-build-and-implementation`
