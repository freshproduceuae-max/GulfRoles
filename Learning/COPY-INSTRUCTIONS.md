# Copy Instructions

Use this file when moving the website planning skeleton into a new project.

## Copy Steps

1. Copy the entire `Small Business Websites/` folder into the root of the new project.
2. Put the owner's photos into `reference-materials/images/`.
3. Put the logo and any brand files (colors, fonts) into `reference-materials/brand-assets/`.
4. Put existing copy, menus, price lists, or notes into `reference-materials/copy/`.
5. Put reference/inspiration sites into `reference-materials/inspiration/` or `reference-materials/links/link-list.md`.
6. Open the project in your AI environment.
7. Use a clear instruction such as:

`Refer to the Small Business Websites folder so we can begin.`

## Expected AI Behavior

The AI should:

1. read `START-HERE.md`
2. read `README.md`
3. read `canonical-paths.md`, `phase-dependency-map.md`, `session-resume-protocol.md`, and `lessons-learned.md`
4. create or resume `docs/tracking/progress.md`
5. capture execution preferences (phase 00)
6. run business discovery (phase 01)
7. collect brand and content, confirming the full service/product list (phase 02)
8. inventory and map every image and the logo to real files (phase 03)
9. agree the site architecture (phase 04)
10. build the site, keeping every referenced asset a committed file (phase 05)
11. wire up conversion paths — WhatsApp, quote/booking, call (phase 06)
12. deploy and verify the live URL (phase 07)
13. write the owner a plain-language maintenance guide (phase 08)
