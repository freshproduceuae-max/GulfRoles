# 06 Conversion and Integrations

Goal: make it easy for a visitor to become a customer, and wire in only the integrations the business actually needs.

Files:

- `conversion-prompt.md`
- `conversion-plan-template.md`

## Dependencies

- `docs/business/business-profile.md`
- `docs/architecture/site-architecture.md`
- `docs/features/feature-list.json`

## Required Output

- `docs/conversion/conversion-plan.md`

## Success Criteria

- the primary action (call, WhatsApp, quote, booking) is obvious and repeated
- WhatsApp/quote forms work without a backend where possible (pre-filled messages)
- basic SEO in place (title, meta description, sensible headings, social preview)
- analytics added only if the owner wants it
- no personal data placed in URLs; forms behave safely

## Exit Criteria

- `docs/conversion/conversion-plan.md` exists and is populated
- conversion paths verified to work
- progress tracker updated

## Handoff

- next phase is `07-deployment-and-launch`
